Vibe Coding
Interview Instructions to be-shared beforehand
In the technical interview, be ready to walk through one/several technical solutions from your past projects in depth.
The technical interview includes a vibe coding exercise, to be prepared before the interview.
- For this exercise you are required to have a vibe coding environment (CLI or IDE plug-in only) running on your laptop, that you can use during the interview.
- You are also required to have prepared a simple, vibe coded app that follows this spec : Build an app with a UI/front-end exposing an AI agent that is able to accurately give you the weather when prompted in natural language. For example, the app should accurately answer the following questions : “Hey, how cold is it in Paris?” or “Will it rain in New York tomorrow?”.
Useful ressources :
https://open-meteo.com/
https://nominatim.openstreetmap.org/search
You will not be evaluated on the complexity of the app. Ideally, your application is generated with a single prompt.
 
Expect to be asked to share your code and show your development environment to the interviewer via screen sharing.
We accept any vibe coding environment including non Mistral solutions. Should you want to use Mistral here are some useful links:
Vibe code documentation: https://docs.mistral.ai/vibe/code/overview
AI Studio documentation: https://docs.mistral.ai/studio-api/overview
AI Studio link: https://console.mistral.ai/home"
Lastly note that solutions are available through a free tier.
